# خطة إقفال Eyadex وإطلاق الإنتاج

> سجل متابعة للعمل المطلوب في المحادثة، وفق قواعد التسليم الموجودة في `.claude/skills/eyadex-delivery-loop/SKILL.md`. هذا المستند ليس مصدر صلاحية تنفيذ أو موافقة تشغيل؛ القرارات والصلاحيات مصدرها تعليمات المالك الموثوقة والقواعد الحاكمة، ولا تثبت مربعات الخطة وحدها اجتياز أي بوابة.

**الهدف:** إقفال قبول F3، وتسليم PDF الفواتير والإيصالات، والتحقق من التجهيز الطبي ودورة العيادة، ثم إطلاق إنتاج بأدلة تشغيل وقبول مكتملة.

**المعمارية:** يستمر `ApiClient` بعقديه HTTP وmock، وعزل العيادات والصلاحيات في API وPostgreSQL. يصدر PDF من السيرفر وفق التصميم المعتمد، وتحدد قياسات staging تنفيذه داخل API أو worker. كل دفعة PR مستقل ومراجعة وتجربة staging ثم merge commit؛ لا إعادة كتابة لتاريخ `main` أو `lovable`.

**التقنيات:** TypeScript، NestJS/Fastify، PostgreSQL 18/RLS، pnpm 12.5.1، Node 24، TanStack Start، Typst؛ اعتماد Amiri/qpdf وتثبيت أدوات الاستخراج تأكد من المالك في 2026-11-03.
