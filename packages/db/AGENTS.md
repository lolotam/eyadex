# packages/db rules

- The Drizzle schema in `src/schema` mirrors `db/sql` and is checked by `schema-drift.db.spec.ts` (columns with defaults/identity/generated, primary keys in order, foreign keys with their actions, full index definitions, CHECK definitions, the view); a new CHECK is written exactly as `pg_get_constraintdef` prints it, and a database default exactly as `column_default` prints it; `db/sql` stays the source of truth until the switchover — so the two can never silently diverge.
- Drizzle's `.desc()` means `DESC NULLS LAST`; PostgreSQL's plain `DESC` is `NULLS FIRST` — mirror a plain `DESC` index column as `.desc().nullsFirst()`.
- `drizzle-kit` is inspection only (ADR-0024): `pnpm --filter @eyadex/db db:pull` with `DRIZZLE_DATABASE_URL` pointing at a database migrated by `db/migrate.sh` writes a read-only introspection into the gitignored `.drizzle-pull/`. Use its `schema.ts` as a starting point for a new mirror file, then re-check composite key column order and expression indexes against the SQL (the pull gets both wrong). `drizzle.config.ts` refuses every other command; `schema-drift.db.spec.ts` stays the comparator.
